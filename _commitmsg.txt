멀티 PC 배포 & 운영: 인증 게이트 + 머신 헬스 + Windows 서비스화

여러 Windows PC에 Collector를 배포하고 Web UI를 공개 호스팅(Vercel)하며
운영(헬스/로그/보안)까지 가능하게 함.

Supabase (schema.sql):
- events 읽기 RLS를 authenticated 전용으로 변경(공개 배포 안전장치: anon 키가
  노출돼도 로그인 없이는 못 읽음).
- machines 헬스 테이블 신설 + 인덱스 + Realtime + 읽기 RLS.

Collector:
- health.py HealthReporter: machines에 하트비트 upsert(폴링 루프 틱, 별도 스레드 X).
- 파일 로그(크기 기반 로테이션) + heartbeat_interval/log_file 설정.
- config 로더 BOM 내성(utf-8-sig) — PowerShell이 쓴 config.json도 로드.
- 배포 템플릿 redact 기본 ON.

Web UI:
- Supabase Auth 로그인 게이트(미로그인=데이터 차단), 로그아웃, 사용자 표시.
- 머신 헬스 바: machines 조회+Realtime로 온라인/stale 표시.
- Vercel 배포: generate-config.js(env→config.js) + vercel.json.

Windows 서비스화 (deploy/windows):
- install/uninstall/run ps1. 작업 스케줄러 등록(로그온 시 자동시작 + 실패 시
  재시작, pythonw 무콘솔), config.json 생성(service_role 키 입력, redact ON).

문서: docs/DEPLOY.md(멀티 PC 배포 절차·보안 체크리스트), README 갱신.

검증: pytest 22(기존 19 + health 3) 통과. MCP로 스키마 적용·머신 헬스 확인.
Playwright로 로그인 게이트(anon 차단 / 로그인 후 데이터·헬스칩) PASS.
generate-config.js env 주입 확인. Collector 하트비트·파일로그 실동작 확인.

범위 밖: 보존정책 prune(무료 티어 용량 주의는 문서화), mac/Linux 자동실행.
