⌖ 새 비밀번호 설정
메일 링크로 들어오셨습니다. 새 비밀번호를 입력하세요.
⬇ Collector 설치 (Windows)
더블클릭 → 설치(무관리자) → 관리자에게 받은 디바이스 토큰 붙여넣기 → 끝. 제거는 설정 → 앱.
🛰 API 프록시 서버 설치 (선택)
트래픽 로깅·통제 서버. 설치 후 더블클릭 실행. 켜기/끄기(라우팅)는 Collector 트레이 패널에서.
🐳 Agent 런처 설치 (선택)
VS Code 없이 컨테이너로 에이전트 격리 실행. Docker 필요. 실행: periscribe-agent <작업폴더> --name <이름>
머신 관리
⬇ Collector 설치 (Windows) 더블클릭 설치(무관리자) → 발급 토큰 붙여넣기 → 끝. 제거는 "프로그램 추가/제거". 🛰 API 프록시 서버 설치 (단독·선택) 🐳 Agent 런처 설치 (Docker·선택)
세션 관리
선택한 세션을 영구 삭제합니다 — 중앙 DB는 즉시, 수집 PC 로컬 파일은 온라인일 때.
🔐 암호화 설정 (최초 1회)

로그 내용을 종단간 암호화합니다. 운영자도 복호화할 수 없습니다. 이 패스프레이즈는 서버로 전송되지 않으며, 분실 시 복구코드로만 복구됩니다.
