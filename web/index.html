🛰 API 프록시 토글 다운로드 (Windows, 선택)
더블클릭 → Claude API 게이트웨이(로깅+통제) 켜기/끄기 GUI. Collector 설치 후 사용.
🗑 제거 파일(uninstall.bat) 다운로드
머신 관리
⬇ Collector 다운로드 (Windows) 실행 → 발급 토큰 붙여넣기 → 끝. (Python 불필요) 🐳 Agent 런처 (컨테이너 실행, Docker 필요) 🛰 API 프록시 토글 (더블클릭 ON/OFF, Collector 필요) 🗑 제거 파일 (uninstall.bat)
