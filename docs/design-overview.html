🔑 키 계층

🛡 제로지식 경계 구현

  • 운영자가 보는 것: 암호문 payload · 공개키 · 봉인DEK · 메타데이터(누가·언제·무슨 도구·실패여부)
  • 운영자가 못 보는 것: 패스프레이즈 · 개인키 · 평문 DEK · payload 내용
  • ⚠ 한계: 복호화 웹 JS를 운영자가 서빙 → 악의적 운영자의 키 탈취는 못 막음 (= at-rest 제로지식까지가 떳떳한 주장 범위)

🔁 디바이스 연속성(재설치) 구현

  • 삭제·재설치해도 machine_guid(Windows MachineGuid)로 같은 device 행에 자동 연결 — 관리자 매칭 불필요
  • 재설치 = 새 DEK 세대 → dek_keys에 누적(덮어쓰기 X)
  • 옛 로그(옛 kid)는 옛 봉인DEK로 계속 복호 — 봉인본은 DB에 남음(사라지는 건 로컬 평문뿐)
  • revoke/제거됨 guid는 차단(재설치해도 안 되살림)
