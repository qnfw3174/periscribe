⌖ Periscribe — 시스템 구성도

대상 PC(컬렉터+프록시) → Supabase(암호문 저장) → 관리자 브라우저(복호 열람). 화살표 = 데이터 흐름.

API 라우팅/중계 — Claude→프록시→Anthropic 로컬 기록 — transcript·spool 쓰기 컬렉터 읽기 업로드(E2EE) — 컬렉터→Supabase 관리자 열람 — 웹/Supabase↔브라우저

⚠ 프록시는 자체 업로드 불가 — 같은 PC의 컬렉터가 spool을 읽어 올려야 웹에 뜬다. 컬렉터·프록시 분리(독립 프로세스) + 가디언 없음(프록시 죽으면 수동 proxy off).
