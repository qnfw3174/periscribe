# Periscribe — 사용 시나리오 플로우차트

> 관리자/사용자 관점의 사용 흐름. Mermaid 플로우차트(GitHub·VS Code 렌더). 바로 보려면 `usage-flows.html`.
> ⚠ 표시 = 아직 커버 안 된 부분(GAP).

---

## F1. 관리자 온보딩 / 재방문

```mermaid
flowchart TD
  S(["관리자 웹 접속"]) --> L{"계정 있음?"}
  L -- "아니오" --> SU["가입 ⚠G1: 현재 Supabase 콘솔서 수동 생성"]
  L -- "예" --> LI["로그인 (이메일+비번)"]
  SU --> LI
  LI --> K{"owner_keys 있음?"}
  K -- "아니오 (최초)" --> SET["암호화 패스프레이즈 설정<br/>+ 복구코드 저장(1회)"]
  K -- "예" --> UN["패스프레이즈 입력 = 잠금해제"]
  SET --> APP(["대시보드 진입"])
  UN -- "성공" --> APP
  UN -- "실패" --> Q{"패스프레이즈 분실?"}
  Q -- "아니오" --> UN
  Q -- "예" --> REC["복구코드로 복원 + 새 패스프레이즈"]
  REC --> APP
```

## F2. 머신 설치 → 수집 → 표시

```mermaid
flowchart TD
  A(["관리자: 머신 관리 → 토큰 발급"]) --> B["사용자에게 토큰 전달"]
  B --> C["사용자: periscribe.exe 실행 + 토큰 입력"]
  C --> D["자동 설치(부팅 자동시작) + 백그라운드 실행"]
  D --> E{"관리자 암호화 키 설정됨?<br/>(owner 공개키 존재)"}
  E -- "아니오" --> F["적재 보류 ⚠G9: 무손실 대기<br/>(평문 안 올림)"]
  F --> E
  E -- "예" --> G["per-device DEK 생성 → 공개키로 봉인 업로드"]
  G --> H["transcript 새 줄 → payload 암호화 적재"]
  H --> I(["웹에서 실시간 복호 표시 🔓"])
```

## F3. 디바이스 수명주기 (관리자·사용자 행동 → 결과)

```mermaid
flowchart TD
  ON(["디바이스 활성/온라인"])

  ON --> ADM{"관리자 행동"}
  ADM -- "잠깐 중단·보안" --> RV["revoke<br/>토큰 차단 · 로그 보존"]
  RV --> RVQ{"이후"}
  RVQ -- "재활성" --> RES["revoked 해제"] --> ON
  RVQ -- "완전 폐기" --> DEL["삭제(purge)<br/>디바이스+로그 영구 제거"]
  ADM -- "완전 폐기" --> NEED["먼저 revoke 필요(2단계)"] --> DEL
  DEL --> GONE(["목록에서 사라짐"])

  ON --> USR{"사용자 행동"}
  USR -- "재설치(같은 PC)" --> RI["machine_guid로 같은 디바이스 연속<br/>(새 DEK 세대 누적, 옛 로그 유지)"]
  USR -- "uninstall(제거파일)" --> UH["'제거됨' 표시 + 컬렉터 종료"]
  UH -- "재설치" --> RI
  RI --> ON

  RV -. "사용자가 그 PC 재설치" .-> BLK["🚫 차단(관리자 revoke는 안 되살림)"]
```

## F4. 로그 조회 / 과거 세션 불러오기

```mermaid
flowchart TD
  A(["대시보드(잠금해제됨)"]) --> B["세션 목록: 최근 변경순<br/>적재(건수) / 미적재 표시"]
  B --> C{"세션 선택"}
  C -- "적재됨" --> D["로그 표시"]
  D --> D2{"더 과거 필요?"}
  D2 -- "예" --> D3["'더 불러오기'(페이지네이션)"] --> D
  C -- "미적재" --> E["'이 세션 불러오기'(백필 요청)"]
  E --> F{"수집 PC 온라인?"}
  F -- "예" --> G["컬렉터가 처음부터 재적재 → 실시간 복호 표시"]
  F -- "아니오" --> H["대기: PC 켜지면 자동 채워짐"]
  G --> D
  D --> FIL["필터: 머신·세션·kind·심각도·카테고리·컨테이너·검색·실패만"]
```

## F6. 제거 vs 삭제 vs 차단 — 무엇을 쓸까

```mermaid
flowchart TD
  Q(["이 머신을 어떻게?"]) --> A{"목적"}
  A -- "잠깐 멈춤·기록 유지" --> RV["관리자 revoke<br/>→ 필요시 재활성"]
  A -- "클라만 다시 깔기" --> RE["uninstall.bat 말고 새 exe로 재설치<br/>(연속성 유지)"]
  A -- "이 PC 완전 정리(클라+로컬)" --> UN["uninstall.bat<br/>(제거됨, 재설치 시 되살아남)"]
  A -- "DB에서 완전 폐기(로그까지)" --> DL["머신 관리 → revoke → 삭제"]
```

## 커버 안 된 부분(GAP) — 흐름상 위치

| GAP | 위치 | 심각도 |
|---|---|---|
| G1 회원가입 UI 없음 | F1 가입 | 높음(셀프서비스면) |
| G2 패스프레이즈 변경(아는 상태) UI 없음 | F1/F5 | 중 |
| G9 키 설정 전 설치 혼선(보류 안내 부족) | F2 보류 | 중(UX) |
| G4 transcript 삭제 시 카탈로그 잔재 | F4 목록 | 낮음 |
| G5 같은 토큰 2대 입력 | F2 설치 | 낮음 |
| G6 OS 재설치 시 옛 디바이스 잔존 | F3 | 낮음 |
| G8 크로스세션 삭제 미반영 | F3 삭제 | 낮음 |
