✅ Periscribe — 테스트 체크리스트

자동 = pytest 로 사용자 개입 없이 검증됨 · 수동 = 실사용자가 실제 환경에서 확인

A. 자동 테스트 (사용자 개입 없음)

순수 로직·파이프라인·프록시 동작을 71개 단위/통합 테스트로 검증합니다. 실행:

cd collector
python -m pytest tests -q        # 전체
python -m pytest tests -v        # 항목별
영역테스트 파일검증 내용
파싱test_parser.py모든 이벤트 종류, 방어적 파싱, 레닥션, container_id 스탬프, sidechain
수집 파이프라인test_collector.pyEOF/백필/재시작 오프셋, 체크포인트 재개, 카탈로그, 세션 삭제, DEK 부트스트랩, container_id
적재(sink)test_sink.py · test_health.pyNUL 제거, 키 정규화, poison 행 격리, 네트워크 오류 전파, config 검증
E2EEtest_crypto.pyDEK 생성, AES-256-GCM 암복호 라운드트립, RSA 봉인/해제, sink 암호화
프록시 통제test_apiproxy.py요청 차단·레닥션·주입, trailing-only 매칭, 도구 게이팅, 합성응답, 인증서(SAN/CA재사용)
프록시 라우팅test_proxy_failsafe_e2e.py서버 헬스 기반 ON/OFF, lockout 방지(직결 덮어쓰기), env 의미, orig 보관·복원
프록시 동시성test_proxy_concurrency.py32 동시요청, 반열림 연결, 스트림+헬스, 중단 스트림 복구
OS 감사test_audit.pySysmon Claude 서브트리만 캡처, terminate 정리, deny image, ingest
컨테이너+프록시test_agent.py--proxy docker 인자 생성, CA 없을 때 거부, bind 경고
위 영역은 코드 변경 시 자동으로 회귀 검증됩니다. GUI·Docker·브라우저·실제 Claude 가 필요한 부분은 아래 수동 테스트로 확인합니다.

B. 실사용 수동 테스트 체크리스트

실제 환경(Windows 데스크톱 / Docker / 브라우저 / 실제 Claude Code)이 필요한 항목입니다.

B-1. 설치 / 제거

☐기능절차기대 결과
☐컬렉터 설치periscribe-setup.exe 실행 → 토큰 입력무관리자 설치 + 트레이 패널 + 자동시작 등록. 임시폴더(_MEI) 안 생김
☐프록시/에이전트 설치각 setup.exe 실행각자 폴더에 설치, 시작 메뉴 바로가기
☐제거설정 → 앱 → 제거파일 삭제 + (컬렉터) 서버에 제거신호·자동시작 해제·데이터 삭제. 웹에 🗑제거됨 표시

B-2. 컬렉터 · 트레이

☐기능절차기대 결과
☐수집 → 웹 표시Claude Code 로 한 턴 실행잠시 후 웹 세션 피드에 프롬프트/응답/도구 이벤트 표시
☐트레이 최소화패널 창 X 클릭트레이 아이콘으로 들어감 → 우클릭 "열기"로 복귀, "종료"로 종료
☐헬스바웹 상단 확인이 머신이 🟢 온라인으로 표시(주기적 하트비트)
☐과거 백필웹 세션 관리 → 과거 백필그 세션의 과거 이벤트가 처음부터 채워짐(중복 없이)
☐OS 감사(선택)관리자로 audit-setup → Claude 가 쉘 작업웹 🐚 OS 탭에 프로세스 실행 이벤트(Claude 서브트리만)

B-3. 에이전트 (컨테이너 격리)

☐기능절차기대 결과
☐컨테이너 실행periscribe-agent <폴더> --name box1컨테이너에서 Claude 진입, transcript 가 웹 🐳box1 로 수집
☐망 차단 정책정책 "network": false 후 재실행 → 컨테이너에서 외부 접속 시도네트워크 차단됨(접속 실패)
☐작업폴더 읽기전용정책 "workspace_writable": false → 파일 쓰기 시도쓰기 거부(읽기전용)

B-4. 프록시 · 통제 (호스트)

☐기능절차기대 결과
☐프록시 ON 라우팅프록시 서버 실행 → 패널에서 프록시 켜기 → Claude 한 턴웹 🛰 API 에 요청/응답 기록. (최초 1회 Claude 재시작 필요할 수 있음)
☐요청 차단 → "취소"정책 block_patterns:["aaaa"] → 프롬프트에 aaaaassistant 가 "취소"로 응답(에러 아님). 다음 프롬프트는 정상
☐도구 게이팅정책 gate_tool_use:true, tool_block_patterns:["\\brm\\b"] → "파일 삭제해줘""파일 삭제 - 차단" 표시, 실제 파일 안 지워짐
☐레닥션정책 redact_patterns:["TOKEN=\\S+"] → 프롬프트에 토큰 포함전송 전 마스킹([REDACTED]) — Anthropic 으로 원문 안 나감
☐프록시 OFF패널에서 프록시 끄기즉시 Anthropic 직결로 전환(로깅 중지)

B-5. 컨테이너 + 프록시 (연계)

☐기능절차기대 결과
☐컨테이너 프록시 라우팅① config api_proxy_bind:"0.0.0.0" → 프록시 서버 실행 ② periscribe-agent --proxy <폴더>컨테이너 Claude 트래픽이 웹 🛰 API 에 기록(차단 정책도 적용)
☐CA 없을 때 안내프록시 서버 한 번도 안 띄우고 --proxy"프록시 서버를 먼저 실행하세요" 안내 + 중단 (이 분기는 자동 테스트로도 검증됨)

B-6. 웹 대시보드

☐기능절차기대 결과
☐로그인 + E2EE 복호관리자 로그인 → 패스프레이즈 입력이벤트 내용이 복호되어 표시(서버엔 암호문만)
☐토큰 발급/revoke머신 관리 → 발급 / revoke토큰 1회 표시, revoke 시 그 머신 적재 즉시 무효
☐출처 탭전체 / Transcript / API / OS 전환로깅 경로별로 필터링, 같은 대화는 한 세션으로 묶임
☐통제 현황 KPI차단 발생 후 헬스바 아래 확인🛡차단 카운트 증가, "🛡 차단만" 토글 시 차단 이벤트만 표시
☐위험 분류 필터심각도 🔴크리티컬 선택파괴/권한/자격증명 등 위험 동작만 표시
☐실시간 갱신새 이벤트 발생새로고침 없이 피드에 즉시 추가(Realtime)
⚠ 제거(B-1) 테스트는 실제 데이터/토큰을 삭제·revoke 하므로, 운영 머신이 아닌 별도 테스트 환경에서 수행하세요.
